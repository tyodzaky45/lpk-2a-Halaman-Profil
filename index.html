01. Profil Singkat

Tentang Saya

Berdedikasi menggabungkan logika algoritma, struktur data yang bersih, dan antarmuka modern.

Perkenalkan, saya Tyo Dzaky Firmansyah, mahasiswa aktif Program Studi Teknik Informatika (Kelas TI24E) yang memiliki ketertarikan mendalam pada rekayasa perangkat lunak, pengolahan multimedia berbasis kecerdasan buatan, serta perancangan sistem basis data yang andal.

Dalam pengembangan web, saya terbiasa membangun sistem informasi dinamis menggunakan PHP, HTML5, dan CSS modern dengan perhatian khusus pada keterbacaan kode dan pengalaman pengguna yang responsif. Di sisi lain, eksplorasi saya pada ekosistem Python mencakup pemisahan instrumen audio (source separation) menggunakan Demucs, pengolahan dan peningkatan resolusi citra dengan OpenCV serta Real-ESRGAN, hingga implementasi algoritma kriptografi.

Clean Web Architecture
